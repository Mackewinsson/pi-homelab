# Scraper (Raspberry Pi)

## Quick start

```bash
cd ~/projects/scraper
source .venv/bin/activate
python -m src.scraper
```

Or: `./scripts/run.sh`

## From your Mac

```bash
ssh pi
cd ~/projects/scraper && source .venv/bin/activate
```

## Add Playwright later (optional)

```bash
pip install playwright
playwright install chromium
```
